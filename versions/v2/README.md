# A general-deficit extension of Shao and Zhao's Italian cycle-domination formulas

**Authors:** Haobo Ma, Wenlin Zhang

By a gap decomposition, we extend Shao and Zhao's Theorem 7.1 (2026, arXiv:2610.00108v1, pp. 22-24) to every deficit, answering the fourth future-work direction in their Section 9, p. 29: a finite binomial sum counts Italian dominating functions of weight 2n-j on a labelled cycle for every n >= 3 and 0 <= j <= 2n. Marking a vertex counts periodic words without passing to rotation classes. The same decomposition gives a rational bivariate generating function, the total-count recurrence requested in the second direction, and a sufficient polynomial stable range. The exclusion polynomial has degree j-4 and leading coefficient 2/(j-5)! for j >= 5; paths have the same total-count growth ratio as cycles.
